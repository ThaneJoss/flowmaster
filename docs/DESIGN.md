# FlowMaster 视觉与交互规范

Vue 3 单页应用沿用原项目的浅灰底色 #f6f7f9、白色卡片、蓝色主色 #2563eb、深色正文 #182230 与辅助文字 #68758a。面板使用 14–16px 圆角，按钮、输入框与提示一致。

桌面为导航 + 假设列表 + 流程画布 + 节点详情；窄屏自动堆叠，导航可横向滚动。画布支持滚动、缩放、适配、拖动和键盘调整。节点状态使用文字与色彩共同表达。

自动布局按依赖顺序和画布实际宽度排列成蛇形网格，空间不足时向下换行，换行连线经过行间或外侧空隙。新增节点在当前画布宽度内寻找空位，保留已有节点位置。卡片为 200×156px，标题最多展示三行，悬停或选择节点可查看完整标题。自动布局保存成功后恢复可读比例；“适配”最低缩放到 75%，过宽时提示使用自动布局。窗口尺寸变化不会自动写入节点坐标，手动缩放仍可缩小到 25%。单列长图的坐标上限为 30,000px，支持最多 120 个节点向下排列。

UiButton、UiField、UiModal 是 Vue 可复用组件。弹窗使用浏览器对话框的焦点管理和 Escape 语义，由 Vue 管理内容与状态。研究内容以文本呈现，不渲染不受信任的 HTML。

空工作区不自动加载示例。实验结果由用户手动录入，保留历史分析记录的来源展示。界面不提供模型配置、模型 Key 输入、模型连接测试或 Agent 分析操作。删除等影响数据的操作先弹出确认。界面日期使用 Asia/Shanghai。

Token 管理保留签发、权限、到期时间和撤销功能；外部 MCP 客户端使用手动配置的 FlowMaster Bearer Token。浏览器与外部客户端均通过 `/mcp` 访问工作区。
