# 交互与视觉规范

## 信息层级

主路径为“项目 → 流程 → 步骤 → 执行记录”。顶层导航为“项目 / 连接与设置”，项目内部为“流程 / 记录 / 资料”。当前项目名称持续可见，子视图共享明确范围，不保留看不到的项目筛选。

新建项目后进入项目，新建流程后选中流程。流程区使用流程列表、画布和步骤详情；记录页供项目内查询与回溯，步骤详情提供局部历史。Token、连接、凭据选项和 MCP 说明集中在设置，不占独立研究入口。

## 步骤与记录

步骤详情优先展示标题、目标、类型、执行进度、开始时间和依赖。研究方法、输入输出、结论与后续行动折叠或按类型显示，避免所有步骤出现同一组长表单。

当前结果只读展示，新增与修正共用记录表单。保存执行记录不会代替保存步骤草稿。执行进度和结果结论使用不同标签。记录可定位流程步骤，已删除步骤使用标题快照说明原归属；无关联旧摘要与历史模型建议有明确标记。数据规则统一见 [API.md](API.md#执行记录与当前结果)。

步骤 / 记录引用当前项目资料；引用阻止删除时，展示服务端原因。删除步骤说明历史保留，删除流程说明记录级联删除。没有额外的隐藏 / 归档状态。

草稿切换和 revision 冲突有明确提示。等待状态限定在相关动作。导出标签说明范围：“导出工作区”包含全部业务集合，“导出记录”包含当前筛选的所有页。

## 画布与视觉

沿用浅灰底色 #f6f7f9、白色卡片、蓝色主色 #2563eb、深色正文 #182230、辅助文字 #68758a，面板圆角 14–16px。状态使用文字与颜色共同表达。桌面三栏，窄屏堆叠。

画布支持滚动、缩放、适配、拖动和键盘调整。自动布局按依赖和实际宽度排列为蛇形网格，空间不足时向下换行，连线经过行间或外侧空隙。新增步骤寻找当前宽度内空位，保留既有位置。

卡片 200×156px，标题最多三行，悬停或选中可查看完整标题。自动布局保存后恢复可读比例；“适配”最低 75%，手动缩放最低 25%。窗口尺寸变化不会自动保存坐标；单列长图坐标上限 30,000px，最多 120 个步骤。

UiButton、UiField、UiModal 保持一致交互，弹窗保留浏览器焦点管理与 Escape 语义。研究内容按文本显示，日期使用 Asia/Shanghai。

空工作区不自动加载示例；导入示例是管理员显式操作。不提供模型配置、模型 Key 输入或模型调用入口。
